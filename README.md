# Legally

Boutique law firm design concept — editorial serif layout on Cloudflare Pages.

**Repo:** https://github.com/bearllc555-spec/legally-site

## Stack

- React 19 + Vite + TypeScript
- Tailwind CSS 3
- Cloudflare Pages + Wrangler

## Development

```bash
npm install
npm run dev
```
